# Requisitos do Sistema TaskFlow

## 1. Objetivo

O TaskFlow é um sistema fictício para gerenciamento de tarefas de uma equipe.

## 2. Requisitos funcionais

- RF01: Permitir o cadastro de tarefas.
- RF02: Permitir a consulta das tarefas cadastradas.
- RF03: Permitir a alteração do status de uma tarefa.
- RF04: Identificar o responsável por cada tarefa.

## 3. Requisitos não funcionais

- RNF01: A interface deverá ser simples e intuitiva.
- RNF02: A documentação deverá ser mantida atualizada.
- RNF03: As alterações deverão ser registradas no Git.
